# Dos Caminos

Juego de plataformas móvil hecho con Phaser 3 y Vite.

## Ejecutar con Docker

```powershell
docker compose up --build
```

Abrir `http://localhost:8080`. Desde un móvil conectado a la misma red, abrir `http://IP-DE-TU-PC:8080`.

## Desarrollo sin Docker

```powershell
npm install
npm run dev
```
